# Трекер привычек (habit_tracker)

Android-приложение для отслеживания привычек. Работает полностью офлайн,
данные хранятся только на устройстве.

**Скачать:** [RuStore](https://www.rustore.ru/catalog/developer/x9jrid)

## Возможности

- **Типы привычек:** да/нет, количество, время (с секундомером), негативные
  привычки (успех / срыв / пропуск).
- **Расписание:** каждый день, по дням недели, раз в N дней или N раз за
  N дней; настраиваемое время начала дня.
- **Главная:** месячный календарь со статусом каждого дня и список привычек
  на выбранную дату с быстрой отметкой.
- **19 шаблонов** в категориях «Здоровье», «Разум», «Продуктивность» или своя
  привычка.
- **Статистика:** текущая и лучшая серия, процент выполнения, графики за
  неделю / месяц / 3 месяца / год, разбивка по привычкам.
- **Карточка привычки:** метрики, недельный график, мини-календарь, таймер.
- **Уведомления:** утренняя сводка, напоминания по привычкам с кнопками
  «Выполнено» / «Напомнить позже», автоповтор, режим «Не беспокоить»;
  восстанавливаются после перезагрузки телефона.
- Поиск, фильтры и ручная сортировка привычек перетаскиванием.
- Светлая, тёмная и системная тема.

## Стек

- Flutter 3.38 / Dart 3.10, Material 3
- `flutter_riverpod` — состояние, `go_router` — навигация
- `drift` + SQLite — база данных
- `flutter_local_notifications` + `timezone` — уведомления
- `shared_preferences` — настройки
- `yandex_mobileads` — рекламный баннер

Платформа: Android 8.0+ (minSdk 26). Сервисы Google не используются.

## Сборка

```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs   # код drift
flutter test
flutter build appbundle --release
```

Для подписи релиза нужен `android/key.properties` (в репозиторий не входит).
Публикация в RuStore автоматизирована через GitHub Actions
(`.github/workflows/rustore_deploy.yml`), ключи берутся из секретов репозитория.

## Структура

```
lib/
├── app/            # MaterialApp, роутер, тема
├── core/           # база данных, уведомления, расчёт расписаний
├── features/       # habits, statistics, notifications, settings, monetization
├── l10n/           # локализация
└── shared/         # общие виджеты
```
