# Design Direction — Notion-style

## Источник

Основной источник дизайн-направления:
- https://github.com/voltagent/awesome-design-md

Выбранный стиль:
- **Notion**

**Официальный Notion DESIGN.md сохранён в проект:** `docs/notion_DESIGN.md`  
Он является главным визуальным референсом — используй его при любой работе с UI.

---

## Цель дизайна

Сделать интерфейс:
- спокойным
- чистым
- дружелюбным
- современным
- удобным для ежедневного использования
- подходящим для календаря, карточек привычек и статистики

---

## Основные визуальные принципы

- warm minimalism
- soft surfaces
- rounded cards
- clean spacing
- readable typography
- light theme first
- restrained accent colors
- calendar-first layout
- card-based composition
- мягкий, неагрессивный UI

---

## Подход к Flutter UI

Использовать:
- Material 3 как техническую базу
- кастомную тему поверх
- мягкие радиусы
- спокойные тени
- нейтральный светлый фон
- аккуратные карточки привычек
- минималистичные графики
- понятные состояния selected / completed / skipped / failed

---

## Что должно ощущаться в интерфейсе

Интерфейс должен напоминать:
- аккуратный personal productivity tool
- не корпоративную панель
- не крипто-дашборд
- не dark-tech IDE

---

## Основные зоны UI

### Главная
- сверху месячный календарь-сетка
- ниже список привычек на выбранный день / период
- много воздуха
- акценты на текущем дне и статусах привычек

### Карточки привычек
- мягкие скругления
- компактные контролы
- понятный прогресс
- хороший контраст текста и цвета

### Статистика
- простые графики
- минимум визуального шума
- акцент на понятности
- аккуратные карточки метрик

### Настройки
- чистый список
- без перегруза
- приоритет важным настройкам уведомлений и истории

---

## Чего избегать

Не использовать:
- glassmorphism
- кислотные градиенты
- dark-first как основной стиль
- перегруженные тени
- neon / cyberpunk
- тяжёлые enterprise dashboard patterns
- избыточные анимации
- слишком плотный интерфейс

---

## Цветовая стратегия

- светлая спокойная база
- умеренные акцентные цвета
- цвета привычек должны быть:
  - различимыми
  - мягкими
  - читаемыми на фоне карточек
- важно учитывать доступность и контраст

Ключевые токены из `docs/notion_DESIGN.md`:
- canvas: `#ffffff`
- surface: `#f6f5f4`
- surface-soft: `#fafaf9`
- hairline: `#e5e3df`
- ink: `#1a1a1a`
- charcoal: `#37352f`
- slate: `#5d5b54`
- primary (purple): `#5645d4`
- rounded lg: `12px`, xl: `16px`

---

## Типографика

Приоритет:
- читаемость
- аккуратные размеры
- хорошие межстрочные интервалы
- спокойные заголовки
- без агрессивной display-типографики

Notion Sans (Inter-based) — базовый шрифт.  
В Flutter используем системный шрифт (Roboto/без кастомного подключения).

---

## Адаптивность

Дизайн должен корректно работать:
- на телефонах
- на планшетах

Важно:
- календарь не должен ломаться
- карточки не должны становиться слишком тесными
- статистика должна масштабироваться аккуратно

Breakpoint: **680px** — выше этого контент центрируется через `AdaptiveContent`.

---

## Инструкция для AI-агента

При проектировании UI:
1. опирайся на этот файл;
2. опирайся на `docs/notion_DESIGN.md` (официальные токены Notion);
3. опирайся на `docs/product_spec.md`;
4. не выдумывай случайный стиль;
5. не уводи UI в dark-tech / fintech / enterprise;
6. сохраняй Notion-like ощущение простоты, мягкости и читаемости.
