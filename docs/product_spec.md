# Product Specification — Трекер привычек

## Мета-информация
- **Тип проекта:** мобильное приложение
- **Разработчик:** соло
- **Фреймворк:** Flutter
- **Платформа:** Android only
- **Магазин:** RuStore
- **Цель:** пассивный доход (реклама + разовая покупка Premium)
- **Режим работы:** 100% offline

---

## 1. Стек и технические ограничения

### 1.1 Платформа
- Android 8.0+ (API 26)
- Поддержка телефонов и планшетов
- Независимость от Google Play Services (GMS) — приложение должно работать на устройствах без GMS

### 1.2 Локальное хранение
- База данных: масштабируемый вариант на уровне SQLite/Drift (не простое key-value хранилище)
- Приложение не использует сервер, облако, аккаунты, синхронизацию, аналитику
- Нет экспорта/импорта данных
- Нет бэкапа

### 1.3 SDK и зависимости
- **RuStore Billing SDK** — разовая покупка Premium
- **Яндекс Mobile Ads SDK** — рекламные форматы Banner и Native
- **flutter_local_notifications** (или аналог без GMS-зависимости) — локальные уведомления
- Уведомления должны использовать Exact Alarms
- Уведомления должны восстанавливаться после перезагрузки устройства (BroadcastReceiver на BOOT_COMPLETED)

### 1.4 Управление историей
- История выполнения привычек хранится по умолчанию (глобальная настройка для всех привычек)
- При превышении **50 МБ** занимаемого объёма — автоматическое удаление самых старых записей
- Пользователь видит текущий объём истории и общее количество записей
- Ручное управление:
  - очистить всё
  - очистить последние N записей (N вводит пользователь, общее количество отображается)
  - полностью выключить хранение истории

## 2. Привычки — типы, логика, поля

### 2.1 Создание привычки
При нажатии на FAB (плавающая кнопка "+") открывается scroll-экран создания с секциями:

**Секция 1 — Выбор основы:**
- Готовые шаблоны популярных привычек (15–20 штук, зашиты локально)
- Кастомное создание с ручной настройкой всех параметров
- Выбор: позитивная или негативная (если у пользователя уже есть оба типа)

**Секция 2 — Визуал:**
- Название (обязательное)
- Короткая заметка/описание
- Визуал на выбор: иконка / emoji / фото с телефона
- Цвет: готовые пресеты + свободный выбор через Color Picker (Hex)

**Секция 3 — Логика и цель:**
- Тип механики: да/нет, количественная, по времени, негативная (избегание)
- Цель и единица измерения (если применимо)

**Секция 4 — Расписание:**
- Тип повторения
- Дата старта привычки

**Секция 5 — Уведомления:**
- Режим: без напоминаний / только общее / общее + индивидуальное
- Настройка индивидуальных времён (если выбрано)

Экран создания = экран редактирования (одна и та же форма).

### 2.2 Разделение на позитивные и негативные
- Позитивные: то, что нужно делать (зарядка, чтение, вода)
- Негативные: то, от чего нужно отказаться (курение, сахар, соцсети)
- Переключатель/вкладки между типами показываются ТОЛЬКО если у пользователя есть привычки обоих типов
- Если все привычки одного типа — вкладки не отображаются

### 2.3 Механики выполнения

#### Да/нет
- Тап по карточке = отметить выполнено
- Повторный тап НЕ снимает отметку
- Статусы дня: выполнено / не выполнено / пропущено без штрафа

#### Количественная
- Цель задаётся числом + единица измерения (стаканы, страницы, отжимания и т.д.)
- На карточке: кнопки − и +, между ними текущее значение
- Тап по числу = ввод точного значения вручную
- Кнопка "Выполнено" (галочка) = сразу засчитать целевое значение
- Перевыполнение допускается и учитывается в статистике
- Тап по остальной области карточки = быстрая отметка выполнения (целевое значение)

#### По времени
- Цель задаётся в минутах/часах
- Кнопка "Выполнено" = засчитать целевое время
- Можно ввести фактическое значение вручную
- Перевыполнение допускается
- Доступна кнопка "Засечь таймер" — встроенный таймер (в детальном экране привычки)

#### Негативная (избегание)
- Отдельная логика: успех = не было срыва
- Статусы дня: успех без срыва / срыв / пропущено без штрафа
- Серия считается по дням без срыва

### 2.4 Несколько отметок в течение дня
- Для количественных привычек и привычек по времени доступен режим пошагового набора прогресса в течение дня
- На карточке: стрелки −/+, число между ними (тап по числу = ввод), кнопка-галочка (= целевое значение)
- Пользователь может добавлять по 1 тапами, ввести число вручную или завершить разом

### 2.5 Статусы дня
Для позитивных:
- выполнено
- не выполнено
- пропущено без штрафа (не влияет на графики негативно)

Для негативных:
- успех (без срыва)
- срыв
- пропущено без штрафа

### 2.6 Автоматический статус
- Если ожидаемый день прошёл и ничего не отмечено — автоматически ставится "не выполнено" (или "срыв" для негативных)
- Пользователь может потом исправить вручную за любой прошлый день

### 2.7 Активность привычки
- Два состояния: **активна** / **неактивна**
- Неактивная привычка:
  - остаётся в списке с визуальной меткой
  - уведомления отключаются
  - период неактивности ИСКЛЮЧАЕТСЯ из расчётов статистики и серий (не искажает данные)
  - вся прошлая история и прогресс сохраняются
  - при повторной активации — серия и статистика продолжаются, "провал" посередине игнорируется

### 2.8 Поля привычки
| Поле | Обязательность | Примечание |
|------|---------------|------------|
| Название | Обязательное | Текстовое |
| Заметка/описание | Опциональное | Короткое текстовое поле |
| Визуал | Опциональное | Иконка / emoji / фото с телефона |
| Цвет | Обязательное | Пресеты + Color Picker |
| Тип механики | Обязательное | да/нет, количество, время, избегание |
| Цель | Зависит от типа | Число + единица измерения |
| Тип повторения | Обязательное | См. раздел 2.9 |
| Дата старта | Обязательное | Задаётся пользователем |
| Режим уведомлений | Обязательное | Без / общее / общее+индивидуальное |
| Дата создания | Автоматическое | Отображается внутри карточки привычки |
| Дней активна | Автоматическое | Рассчитывается, отображается внутри карточки |

У шаблонов все поля заполнены дефолтными значениями, но всё можно отредактировать.

### 2.9 Типы повторения
1. **Каждый день**
2. **Выбранные дни недели** (например: Пн, Ср, Пт)
3. **Каждые N дней** (например: раз в 3 дня)
4. **N раз в N дней** (например: 3 раза в 5 дней)

Для типов 3 и 4:
- Отсчёт периодов ведётся от даты старта привычки
- Для типа 4: по умолчанию система равномерно распределяет дни внутри периода (умное распределение)
- Пользователь может переключиться на ручной выбор дней внутри периода

Неделя считается как **Пн–Вс** (для расчёта N раз в неделю, если применимо).

### 2.10 Время смены дня
- Глобальная настройка для всего приложения
- По умолчанию: **06:00**
- До наступления этого времени — всё ещё считается "вчера"

### 2.11 Серии (Streak)
- Серия считается по **ожидаемым периодам** (не только для ежедневных привычек)
- Для "каждый день": серия растёт, если привычка выполнена каждый ожидаемый день
- Для "выбранные дни недели": серия проверяется только по выбранным дням
- Для "каждые N дней": серия проверяется по ожидаемым дням от даты старта
- Для "N раз в N дней": серия считается по завершённым периодам (фиксированные периоды от даты старта)
- **Пропуск без штрафа** — серия замораживается (не рвётся и не растёт)
- Период неактивности привычки — исключается из расчёта серии

### 2.12 Изменение расписания
- Новое расписание действует ТОЛЬКО на будущее
- Прошлая статистика НЕ пересчитывается

### 2.13 Шаблоны привычек
15–20 шаблонов, зашитых локально, разбитых по категориям:

**Спорт и здоровье:**
- Пить воду (количественная, 8 стаканов)
- Тренировка (по времени, 30 мин)
- Зарядка (по времени, 15 мин)
- Сон до 23:00 (да/нет)
- Прогулка (по времени, 30 мин)

**Продуктивность:**
- Чтение (количественная, 20 страниц)
- Фокус-сессия (по времени, 25 мин)
- Изучение языка (по времени, 15 мин)
- Планирование дня (да/нет)

**Ментальное здоровье:**
- Медитация (по времени, 10 мин)
- Дневник благодарности (да/нет)
- Дыхательная практика (по времени, 5 мин)

**Отказ от вредного (негативные):**
- Не курить (избегание)
- Без алкоголя (избегание)
- Без сахара/сладкого (избегание)
- Без соцсетей (избегание)
- Без фастфуда (избегание)

Каждый шаблон имеет дефолтные: название, иконку, цвет, тип механики, цель. Всё редактируется.

## 3. Уведомления

### 3.1 Общее утреннее уведомление
- Одна сводная нотификация в момент начала нового дня (по настройке, по умолчанию 06:00)
- Содержит список предстоящих привычек на сегодня
- Тап → открывает экран Главная
- Можно выключить в настройках (там же, где время смены дня)

### 3.2 Индивидуальные уведомления
- Настраиваются для каждой привычки отдельно
- Можно задать несколько времён для одной привычки
- Работают параллельно с общим уведомлением
- При создании привычки уведомления включены по умолчанию

### 3.3 Режимы уведомлений для привычки
- **Без напоминаний** — ни общее, ни индивидуальные
- **Только общее** — привычка попадает в утреннюю сводку
- **Общее + индивидуальное** — и в сводке, и свои пуши

### 3.4 Автоповтор невыполненной привычки
- Глобальная настройка: повторять каждые **X минут** (по умолчанию 10 минут)
- Этот же интервал используется для действия "Напомнить позже" из уведомления
- Настраивается в глобальных настройках приложения

### 3.5 Отмена уведомлений при выполнении
- Если привычка отмечена выполненной — все оставшиеся индивидуальные уведомления и автоповторы на этот день автоматически отменяются

### 3.6 Действия в уведомлении (Action Buttons)
- **Отметить выполнено** — сразу засчитывает целевое значение
- **Напомнить позже** — откладывает на X минут (глобальная настройка)
- **Открыть приложение** — открывает Главную и скроллит к привычке

### 3.7 Уведомления для "N раз в N дней"
- По умолчанию: умное распределение напоминаний по дням периода
- Пользователь может переключиться на ручной выбор дней

### 3.8 Тихий период (DND)
- Первый пункт в настройках
- Два режима:
  - заглушить все уведомления (полностью)
  - заглушить на период (пользователь задаёт срок)
- Во время тихого периода никакие уведомления не отправляются

### 3.9 Разрешения
- Если у приложения нет прав на уведомления или Exact Alarms:
  - показать понятную плашку-предупреждение внутри приложения
  - тап по плашке → переход в системные настройки Android

## 4. Экраны и навигация

### 4.1 Нижняя навигация (Bottom Navigation Bar)
| # | Вкладка | Назначение |
|---|---------|------------|
| 1 | Главная | Календарь + план на день/период |
| 2 | Все привычки | Полный список всех привычек с фильтрами |
| 3 | Статистика | Глобальный дашборд |
| 4 | Настройки | Все глобальные параметры |

Кнопка создания привычки: **FAB (плавающая кнопка "+")**.

### 4.2 Экран "Главная"
**Верхняя часть:**
- Полный месячный календарь-сетка
- Текущая дата выделена
- Тап по любой дате — показывает список привычек за этот день
- Дни в календаре визуально отмечены статусами (цвета: выполнено, частично, пропущено и т.д.)

**Нижняя часть:**
- Список привычек на выбранный период
- Показываются И активные, И неактивные привычки за указанный период
- Фильтр: выбрать **N дней** (произвольное число)
- Для прошлых дней: видны статусы, можно редактировать

**Поведение при переходе из уведомлений:**
- Общее уведомление → открывается Главная (сегодняшний день)
- Индивидуальное уведомление → открывается Главная, автоматически скроллится к нужной привычке

### 4.3 Экран "Все привычки"
- По умолчанию показываются только **активные** привычки
- Доступные фильтры:
  - позитивные / негативные
  - активные / неактивные
  - по срокам (ручной ввод периода)
- Ручная сортировка привычек (drag & drop)

### 4.4 Экран "Статистика"
- Глобальный дашборд по всем привычкам
- Метрики:
  - идеальные дни (100% выполнения всех запланированных привычек)
  - общий процент успешности
  - графики активности
- Фильтры: **дни / недели / месяцы / год**
- По умолчанию: **последний месяц (скользящий период)**
- Скользящий = "последние 30 дней от сегодня", а НЕ "с 1-го числа месяца"

### 4.5 Экран "Настройки"
Порядок пунктов:
1. **Заглушить уведомления / Заглушить на период** (DND)
2. Время начала нового дня (по умолчанию 06:00)
3. Общее утреннее напоминание (вкл/выкл)
4. Интервал автоповтора / "Напомнить позже" (по умолчанию 10 мин)
5. Управление историей:
   - текущий объём (МБ)
   - общее количество записей
   - выключить хранение
   - очистить последние N записей (N вводит пользователь)
   - очистить всё
   - информация: автоудаление при >50 МБ
6. **Premium** (статус покупки / кнопка покупки)

### 4.6 Карточка привычки в списке (на Главной и в "Все привычки")

**Элементы карточки:**
- Иконка/emoji/фото привычки
- Название
- Индикатор прогресса (если применимо)
- Кнопки **−** и **+** (для количественных и по времени)
- Текущее значение между кнопками (тап = ввод точного числа)
- Кнопка-галочка (= сразу поставить целевое значение)
- Кнопка/иконка для открытия детального экрана привычки

**Поведение тапов:**
- Тап по области карточки (вне кнопок) = быстро отметить выполнение
- Повторный тап НЕ снимает отметку
- Долгое нажатие = открыть детальный экран привычки
- Тап по иконке/кнопке "подробнее" = открыть детальный экран привычки

### 4.7 Детальный экран привычки
Состав экрана:
- Название, иконка/фото, цвет
- Статус: активна / неактивна (переключатель)
- Тип механики, цель, расписание
- Кнопки быстрого выполнения (включая кнопку таймера для привычек по времени)
- Месячный календарь-сетка с цветовыми статусами дней
- Дата создания привычки
- Количество дней, которые привычка активна
- Метрики:
  - текущая серия
  - лучшая серия
  - всего выполнений
  - процент успешности
- Графики (bar chart по дням/неделям)
- Кнопка **Редактировать**
- Кнопка **Удалить**

### 4.8 Экран создания/редактирования привычки
Один длинный scroll-экран с секциями:
1. Выбор основы: шаблон или кастомная (позитивная/негативная)
2. Название, визуал (иконка/emoji/фото), цвет
3. Логика и цель (тип механики, число, единица измерения)
4. Расписание (тип повторения, дата старта)
5. Уведомления (режим, индивидуальные времена)

### 4.9 Экран Paywall (Premium)
- Красиво оформленный экран
- Сравнение Free vs Premium
- Зачёркнутая цена 150 ₽, актуальная цена 100 ₽
- Кнопка покупки (RuStore Billing)
- Открывается:
  - при попытке создать 6-ю привычку
  - из раздела Premium в настройках

## 5. Монетизация

### 5.1 Free-версия
- Максимум **5 привычек** (считаются ВСЕ: активные + неактивные)
- Реклама Яндекса
- Полный функционал приложения (графики, статистика, таймер, все типы привычек — всё доступно)

### 5.2 Premium-версия
- Тип покупки: **разовая, навсегда** (RuStore Billing)
- Цена: **100 ₽** (отображается как "было 150 ₽, сейчас 100 ₽" — постоянная акция)
- Что даёт:
  - полностью убирает рекламу
  - снимает лимит привычек (безлимит)
- Больше никаких функциональных ограничений между Free и Premium

### 5.3 Реклама Яндекса
**Форматы:**
- **Banner** — сверху экрана (не снизу, чтобы не конфликтовать с Bottom Navigation)
- **Native** — внутри длинных списков

**НЕ используются:**
- Interstitial (полноэкранная)
- App Open (при открытии)
- Rewarded (видео за вознаграждение)

**Экраны с рекламой:**

|-------|----------------|-------------------|
| Главная | ❌ | ❌ |
| Все привычки | ✅ | ✅ |
| Статистика | ✅ | ❌ |
| Настройки | ✅ | ❌ |
| Детали привычки | ❌ | ❌ |
| Создание/редактирование | ❌ | ❌ |
| Paywall | ❌ | ❌ |

### 5.4 Точки показа Paywall
- При попытке создать 6-ю привычку (жёсткий блок)
- Из раздела Premium в настройках (добровольный переход)
- Никаких агрессивных всплывающих окон, баннеров "купи Premium" и триггеров "после N дней"

## 8. Явные исключения из MVP

В MVP не входят:
- аккаунты
- облачная синхронизация
- импорт / экспорт данных
- backup
- веб-версия
- iOS
- сервер
- подписка
- полноэкранная реклама
- paywall-всплывашки без действия пользователя
- dark theme как основной режим

---

## 9. Критерии готовности MVP

MVP считается готовым, если:
- пользователь может создать привычки всех основных типов
- привычки можно быстро отмечать
- работает календарь и план на день/период
- работает редактирование прошлых дней
- есть статистика по привычке и глобальная статистика
- локальные уведомления работают корректно
- есть free / premium разделение
- реклама показывается только в запланированных местах
- приложение стабильно работает offline
- приложение работает без Google-сервисов
- приложение готово к публикации в RuStore
